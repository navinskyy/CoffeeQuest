# ☕ CoffeeQuest

CoffeeQuest is an interactive web platform designed to help users discover and explore coffee shops across Metro Manila. It features a searchable map, personalized filtering options, community-driven reviews and ratings, and social media integration to support both café enthusiasts and business owners.

## ✨ Features

- 🗺️ Interactive map of coffee shops in Metro Manila
- 🔍 Search and filter cafés based on user preferences
- ⭐ User reviews and ratings
- 📱 Social media popularity and integration
- 🏆 Community-driven café rankings
- ❤️ Bookmark favorite coffee shops
- 📍 Café information including location and details
- 📱 Responsive design for desktop and mobile devices

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Leaflet.js (Interactive Maps)
- OpenStreetMap
- Font Awesome

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/navinskyy/CoffeeQuest.git
```

### Navigate to the project

```bash
cd CoffeeQuest
```

### Run the project

Simply open `index.html` in your preferred web browser.

Or, if you're using VS Code:

- Install the **Live Server** extension.
- Right-click `index.html`.
- Select **Open with Live Server**.

## 🎯 Project Objectives

- Provide a searchable, interactive map of coffee shops in Metro Manila.
- Enable filtering based on user preferences, including social media popularity.
- Allow users to leave reviews and ratings that influence café rankings.
- Assist café owners in leveraging social media to reach more customers.
- Promote café exploration and community engagement throughout Metro Manila.
